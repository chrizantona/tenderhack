# EasyTender · поиск и сравнение товаров

**YSL MISIS · НИТУ МИСИС · БИВТ-24-9**

Сервис собирает товарные предложения с Wildberries, Ozon, Яндекс Маркета и из открытых магазинов Рунета. Приводит карточки к общему формату и помогает сравнить цены, характеристики, наличие и условия доставки в одном интерфейсе.

Проект разработан на хакатоне **Tender Hack в Санкт-Петербурге**. Команда YSL MISIS заняла **3-е место**.

## Установка и запуск

### Через Docker

Нужны Git, Docker с Compose, доступ к интернету и свободный порт `8770`.

```bash
git clone https://github.com/chrizantona/tenderhack.git
cd tenderhack
docker compose up --build
```

Интерфейс откроется по адресу [localhost:8770](http://localhost:8770). Docker-образ включает Python-зависимости и браузерные движки для получения данных с площадок.

### Локально на macOS

Нужны Homebrew и Python 3.12+. Из корня репозитория:

```bash
bash scripts/setup_local.sh
source .venv/bin/activate
python3 app/server.py --host 127.0.0.1 --port 8770 --no-qwen
```

Скрипт устанавливает зависимости, Node.js 20, `gost` и браузерные движки, а также настраивает окружение Playwright. Интерфейс доступен по тому же адресу. Флаг `--no-qwen` позволяет запустить поиск без локальной языковой модели.

### Локальная модель Qwen

Qwen подключается дополнительно: помогает извлекать данные из открытых магазинов, восстанавливать парсинг и проверять спорные совпадения товаров. Базовый поиск и сравнение предложений работают без него.

Предусмотренный запуск через MLX требует Mac с Apple Silicon, установленного `mlx-lm` и отдельно загруженной модели. В Linux Docker этот компонент не установлен. Настройка одного сервера и пула моделей описана в [технической документации](TECHNICAL.md#запуск-qwen--flask).

## Основной функционал

| Возможность | Как это работает |
|---|---|
| Поиск по нескольким источникам | Один запрос запускает параллельный поиск на выбранных площадках. |
| Потоковая выдача | Карточки и статусы источников появляются по мере обработки, без ожидания всей выдачи. |
| Сравнение предложений | Доступны сетка карточек, таблица характеристик и группы похожих товаров. |
| Сортировка | По цене, доставке, наличию, оценкам, отзывам и рейтингу продавца — если эти данные доступны. |
| Сопоставление фильтров | Интерфейс показывает фильтры трёх маркетплейсов и позволяет повторить поиск с выбранными значениями. |
| Подробная карточка | Фотографии, описание, характеристики и ссылка на предложение; часть данных догружается при открытии. |
| Выбор региона | Поиск учитывает выбранный город; геолокация помогает выбрать ближайший поддерживаемый регион. |

Группировка использует бренд, модель, текстовые признаки и ценовые различия. Она объединяет похожие предложения для сравнения; точное совпадение комплектации стоит проверить по характеристикам и карточке продавца.

Поддержка фильтров и полнота карточек зависят от источника. Скорость и состав выдачи также зависят от доступности площадок и их ограничений. При ошибке одного источника уже найденные предложения остаются в выдаче, а причина ошибки отражается в диагностике.

## Технологии и инструменты

| Часть проекта | Технологии |
|---|---|
| Интерфейс | HTML, CSS, JavaScript |
| Сервер и API | Python, Flask, HTTP / JSON, потоковый NDJSON |
| Получение данных | requests, curl_cffi, BeautifulSoup, lxml |
| Браузерный парсинг | Camoufox, Playwright, Selenium |
| Сопоставление товаров | Нормализация бренда и модели, TF-IDF, косинусная близость, разделение по цене |
| Локальный LLM-помощник | Qwen2.5-Coder-14B-Instruct, MLX — опционально |
| Окружение | Docker, Docker Compose, Node.js 20, gost |

Отдельный инструмент [`qwen_product_ranker.py`](qwen_product_ranker.py) обрабатывает уже готовые карточки: проверяет релевантность, группирует товары, отмечает ценовые выбросы и ранжирует предложения. Это самостоятельный CLI; группировка веб-приложения реализована в [`app/clustering.py`](app/clustering.py).

## Архитектура и структура проекта

Браузерный интерфейс обращается к Flask API. Агрегатор параллельно запускает адаптеры источников, приводит ответы к общей схеме и передаёт карточки в интерфейс потоком NDJSON. После обработки выполняется общая группировка товаров.

```text
Браузер (HTML / CSS / JavaScript)
                ↓ HTTP / NDJSON
          Flask API → Агрегатор
                           ↓
     Wildberries · Ozon · Яндекс Маркет · Рунет
                           ↓
       Единый формат → Группировка → Выдача
```

```text
tenderhack/
├── app/                     # API, агрегатор, группировка и фильтры
├── frontend/                # Интерфейс поиска и сравнения
├── scripts/                 # Адаптеры площадок и инструменты запуска
│   └── other_runet/          # Открытые магазины и Qwen-помощник
├── product_ranker/           # Модули обработки готовых карточек
├── qwen_product_ranker.py    # Отдельный CLI ранжирования
├── basic_scheme.json        # Общая схема товарных данных
├── examples/                # Примеры карточек
├── tests/                   # Проверки обработки данных
├── docs/                    # Исследование источников и парсеров
├── Dockerfile               # Окружение приложения и браузеров
├── docker-compose.yml       # Запуск сервиса
└── TECHNICAL.md              # Подробные команды, API и устройство поиска
```

### Основные методы API

| Метод | Назначение |
|---|---|
| `GET /api/search` | Результат поиска в JSON |
| `GET /api/search/stream` | Поток результатов и статусов в NDJSON |
| `GET /api/product` | Подробная карточка по источнику и ID или URL |
| `GET /api/filters` | Фильтры площадок и их сопоставление |
| `GET /api/regions` | Поддерживаемые регионы |
| `GET /api/health` | Состояние приложения и его компонентов |

## Демонстрация работы

1. Запустите приложение и откройте [localhost:8770](http://localhost:8770).
2. Введите товарный запрос, например `шины 205/55 R16`, выберите город и источники.
3. Дождитесь карточек, сравните цены и переключите представление между сеткой и таблицей.
4. Откройте предложение, изучите характеристики и перейдите на страницу продавца.
5. После завершения поиска посмотрите группы похожих товаров, если полученных характеристик достаточно для их формирования.

Для проверки отдельного ранжировщика на комплектном примере, без Qwen и обращения к маркетплейсам:

```bash
python3 qwen_product_ranker.py \
  --query "iphone 15 128gb" \
  --cards examples/cards.json \
  --no-qwen
```

Это пример обработки сохранённых карточек. Поиск в веб-приложении обращается к внешним источникам и требует интернета.

## Практическая ценность и развитие

EasyTender помогает собрать предложения для сравнения перед закупкой: увидеть цены на разных площадках, сопоставить характеристики и проверить условия у продавца. Результат хакатона — веб-приложение, адаптеры четырёх источников, общая схема данных и инструменты обработки товарных карточек.

В проекте объединены исследование веб-источников, параллельная обработка запросов, нормализация данных, алгоритмы сопоставления товаров, разработка API и интерфейса, сборка в Docker.

Возможные направления развития:

- Расширить поддержку общих фильтров и выровнять их применение между площадками.
- Добавить сохранение подборок и экспорт сравнительной таблицы.
- Расширить набор проверок на сохранённых ответах источников, чтобы быстрее замечать изменения формата данных.

Устройство парсеров и результаты исследования площадок описаны в [`docs/`](docs/). Подробные команды запуска, переменные окружения и проверки сохранены в [технической документации](TECHNICAL.md).
